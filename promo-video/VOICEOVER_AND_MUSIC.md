# HexaView 90s promo: voiceover and music

Timecodes match the current 90-second cut (`src/Promo.tsx`). The music shape below uses the earlier 45s marks; in the 50s cut the groove starts at 0:16 with the sign-in scene.

## Voiceover script (female)

The 90-second cut uses these lines. They live in `src/vo-lines.json`, anchored to scenes in `src/timeline.json`. After changing a line, run `node scripts-vo.mjs` and then `node scripts-fit.mjs` (which lengthens a scene if its line needs more room), then `node scripts-music.mjs`, and re-render. The current audio is an AI read in Microsoft en-US-AvaMultilingualNeural, made with `node scripts-vo.mjs`. Samples of six voices are in `out/voice-samples/`. To switch, run `node scripts-vo.mjs <voice>` (for example `en-GB-LibbyNeural`), then re-render. Replace the files in `public/audio/vo/` with a professional read (same file names, one file per line) and re-render.

**Casting brief:** Female, British, late 30s to 40s. Warm, low-to-mid register, calm authority: think air-traffic controller or documentary narrator, not announcer. No upspeak, no hard sell. Alternatives to audition: a soft Scottish or Irish accent (trust, warmth) and a neutral transatlantic read for US-heavy campaigns.

**Where to get it:**
- **Human:** Voices.com, Voice123 or Fiverr Pro, with this table as the brief. Ask for a single WAV timed to these marks, plus each line as a separate file.
- **AI, for drafts or a scratch track:** ElevenLabs voice library, filtered to British female narration. Check the commercial-use terms before anything goes live.


## Music: three directions

All three follow the same shape as the edit:

1. 0:00 logo build
2. 0:04 tension
3. **0:12 drop to silence plus a sub-bass "thunk"**
4. 0:16 the beat lands
5. 0:40.5 resolve on a final chord

| Direction | Feel | Tempo | Library search terms |
|---|---|---|---|
| **A. Hybrid tech build (recommended)** | Dark pulsing synths and glitches that open into a confident, anthemic electronic beat | 100–110 BPM | "hybrid cinematic tech", "technology trailer build", "corporate synthwave uplifting" |
| **B. Piano and pulse** | Sparse felt piano over ticking electronics, strings swelling in the second half. More human, more "trust" | 90–100 BPM | "emotional technology piano", "minimal electronic piano corporate" |
| **C. Heartbeat drive** | Percussive, kick-led, like a pulse that steadies once HexaView arrives | 120 BPM | "driving percussive tech", "cyber security pulse trailer" |

Licensed libraries that cover commercial and paid-social use: Artlist, Musicbed, Epidemic Sound, Soundstripe and PremiumBeat. Pick a track with **stems**, so the music can duck under the voice and the drum hit can sit exactly on 0:16.

**Sound-design layer:** These are worth adding even under music:
- **0:04–0:07:** notification pings and digital static.
- **0:07–0:12:** soft "window" whooshes as consoles pop up, and a glassy snap on each broken link.
- **0:12:** a deep sub "thunk" as the mark lands, followed by a shimmer riser.
- **0:16 onwards:** tuned UI ticks as tiles and gauges animate.
- **0:33:** a crisp click on "Approve".
- **0:44:** the same sub "thunk" as a sonic logo.

## Audio in the render

- **Music:** `public/audio/music.wav` is a temporary bed generated by `node scripts-music.mjs`, with the same structure as the brief above. Replace it with a licensed track of the same name and re-render. It ducks under each voiceover line automatically.
- **Render:** `npm run render` writes `out/hexaview-promo-60s.mp4`.
- **Levels:** `musicUnderVoice` and `musicAlone` in `src/Root.tsx` set the music level with and without the voice.
